## Important limitation

GitHub Connector가 로컬 Binary 파일을 직접 전달하는 File 파라미터를 제공하지 않아 일부 ZIP·PNG·JPG 원본 바이트는 이 저장소에 완전 미러되지 않았다. 그러나 AI가 프로젝트 상태를 복원하는 데 필요한 Control, Snapshot, Handoff, Prompt, 핵심 CSS Source, Audit, Hash, Candidate 계보는 저장돼 있다.

원본 Binary가 필요한 작업에서는 이 Catalog의 SHA-256과 원 대화의 Artifact를 대조해야 하며, 파일을 읽지 못했다면 UNVERIFIED로 기록한다.
