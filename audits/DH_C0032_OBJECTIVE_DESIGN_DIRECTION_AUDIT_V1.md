# DH C0032 Objective Design Direction Audit V1

## Trigger

User feedback after C0031: current design feels worse than the earlier direction.

This is treated as material design evidence, not dismissed as mood.

## Diagnosis

C0027–C0031 improved:
- hierarchy consistency;
- CTA restraint;
- mobile density;
- component consistency.

But the same sequence also over-optimized:
- flat black surfaces;
- repeated thin dividers;
- very large white editorial headings;
- removal of nearly all selective elevation;
- reduction of cyan/blue visual memory cues.

The result is clean but can read as an editorial prototype rather than a distinctive paid technical-service brand.

## C0032 strategy

Do **not** return to the old card-heavy/glow-heavy design.

Combine:
- C0031 information architecture and semantic tokens;
- selective elevated surfaces only around important decisions;
- quiet navy/cyan depth;
- smaller hero typography;
- one cyan action accent;
- one grouped pricing/choice surface instead of many independent cards.
