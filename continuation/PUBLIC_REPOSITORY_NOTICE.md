# Public Repository Notice

이 저장소는 사용자의 명시적 선택에 따라 Public으로 운영됩니다.

공개될 수 있는 내용:

- DH 세팅센터 사이트 Candidate와 디자인 결과
- 가격·서비스 범위·정책 초안
- 연락 경로와 운영 문서
- 검증 결과·Answer Pack·Handoff·Rollback 자료
- 디자인 연구와 작업 Prompt

포함하지 않는 내용:

- 비밀번호
- API 토큰과 인증키
- 인증번호
- 결제정보
- `.env`와 비밀키

GitHub에 저장하는 행위는 Active 승격이나 Production 배포가 아닙니다.
