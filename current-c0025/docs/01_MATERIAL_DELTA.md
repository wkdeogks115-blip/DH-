# C0025 MATERIAL DELTA

C0024 achieved the intended rendered appearance but its final layer still mixed raw color values, legacy aliases and component rules in one override file.

C0025:

- introduces named primitive colors and semantic roles,
- maps legacy aliases to the semantic roles so older CSS resolves through one contract,
- keeps one cyan action accent and neutral surfaces,
- adds a distinct interactive-border role with at least 3:1 contrast against the main surface,
- centralizes focus-ring, text, surface, border, action and state colors,
- replaces `premium-restraint-c0024.css` with `dh-design-system-c0025.css`,
- preserves the approved C0024 visual hierarchy, prices, services, application flow and error recovery.

No third-party runtime color package is installed. External systems were used only as research references.
