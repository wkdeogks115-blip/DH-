# C0025 SCOPE AND EXCLUSIONS

## In scope

- semantic color-token foundation
- approved C0024 one-accent direction
- role-based text, surface, border, action, focus and status colors
- legacy variable compatibility aliases
- interactive control-border contrast improvement
- static browser visual parity and computed-style verification

## Out of scope

- full deletion of all historical CSS files
- typography and spacing token migration
- price, service ID, product scope or policy changes
- payment implementation
- deployed Preview and Production
- actual URL navigation runtime
- real mobile device, assistive technology or user testing
